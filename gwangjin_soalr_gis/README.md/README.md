# ☀️ 광진구 노후 공공 태양광 폐패널 최적 수거 거점 선정 GIS 입지-배분 모델
> **Capstone Design Project** | IEA PVPS 연식별 중량 계수 및 p-median 모델을 활용한 탄소중립 수거 물류 체계 구축

본 프로젝트는 광진구 공공 태양광 발전시설의 운영 상태 진단(PR·경제성·자립률)을 바탕으로 교체·폐기 대상 시설을 선별하고, IEA PVPS 연식별 중량 계수 기반의 폐패널 발생 물량(ton)을 가중치로 활용하여 물류 운송 부하(km·ton)를 최소화하는 최적의 수거 거점(Depot)을 도출하는 GIS 데이터 분석 연구이다.

---

## 📌 1. 연구 배경 및 선행연구 검토

* **태양광 폐패널 급증과 지자체 대응:** 국내 태양광 모듈의 기대 수명(20~25년) 도래 및 2023년 생산자책임재활용제도(EPR) 본격 시행에 따라, 2027년부터 급증할 폐패널에 대한 지자체 차원의 선제적 수거 체계 구축이 시급하다 (이태은 외, 2021; 조수빈, 2023).
* **기존 장거리 수송 방식의 한계:** 발생지에서 지방의 고정식 재활용 플랜트로 직접 운송하는 방식은 부피와 중량으로 인한 **물류비 상승, 장거리 수송 시 2차 파손 오염, 차량 탄소 배출 증가**라는 한계를 가진다 (이상헌 외, 2026).
* **연구 목적:** 본 연구는 **광진구 관내 1차 집하 거점(Depot)을 최적화**하여 관내 순회 수거(Milk-run) 과정에서의 물류운송부하($km \cdot ton$) 및 탄소 배출을 최소화하는 GIS 기반 행정 솔루션을 제안한다.

| 연구자 및 연도 | 주요 연구 내용 | 본 연구 반영 사항 |
| **이태은 외 (2021)** | 국내외 폐패널 재활용 동향 및 2023년 EPR 제도 시행 분석 | 광진구 공공 수거 거점 구축 당위성 확보 |
| **조수빈 (2023)** | 태양광 모듈 수명연한 도래 및 2027년 폐패널 급증 예측 | 대상지 선별 및 교체 주기 기준 반영 |
| **Komoto 외 (2025)** *(IEA Task 12)* | 한국 PV 모듈 연식별 중량 계수 제시 (2000년 이전: 114.6 kg/kW, 2001~2010년: 88.7 kg/kW, 2011년 이후: 73.3 kg/kW) | 시설별 설치 연도 기반 정밀 중량(ton) 산출 |
| **이상헌 외 (2026)** | 기존 장거리 운송 방식의 물류 비효율 및 탄소 배출 지적 | p-median 모델을 통한 관내 1차 거점 최적화로 운송부하 최소화 |

## 🛠️ 4. 스크립트별 상세 역할 및 분석 논리
1) scripts/00_download_network.py
역할: 광진구 도로 네트워크 GIS 공간 데이터 구축

상세 내용: OSMnx 라이브러리를 활용해 광진구 전역의 실제 도로망 세그먼트(7,328개)를 수집하여 네트워크 분석용 그래프 파일(gwangjin_road_network.graphml)로 정형화.

2) scripts/01_geocoding.py
역할: 운영 진단 기반 대상 선별 및 IEA PVPS 연식별 중량 계수(kg/kW) 산출

차등 선별: 광진구 18개 공공시설 중 운영 진단(PR·경제성·자립률) 결과 교체·철거가 필요한 Type C/D 13개소만 필터링 (Type A/B 5개소는 가중치 0t 처리).

IEA PVPS 적용: 국제에너지기구의 한국 연식별 모듈 중량 계수(2000년 이전: 114.6 kg/kW, 2001~2010년: 88.7 kg/kW, 2011년 이후: 73.3 kg/kW)를 설비용량(kW)에 적용하여 정밀 중량(총 9.395t, 375장) 산출.

좌표 매칭 후 data/processed/solar_demand_points.csv 저장.

3) scripts/02_location_allocation.py
역할: p-median 입지-배분 최적화 분석 및 Folium 대화형 지도 시각화

p-median 알고리즘: ∑(거리 × 중량) 수치를 최소화하는 최적 입지 탐색.

[시나리오 A] 18개 전체 시설 대상 (이론적 최적지): 최대 물량 발생지인 구의1동주민센터(13.383 km·ton) 도출.

[시나리오 B] 공공 유휴부지 4곳 대상 (현실적 최적 거점): 실제 하역·야적 여건을 갖춘 능동공영주차장 부지(13.989 km·ton) 도출.

비교 검증: 이론적 최적지 대비 현실적 최적 거점의 운송 부하 증가율이 단 4.5% 미만에 불과함을 입증하여 물류 효율성 손실 없는 수거 거점 정당성 확보.

대화형 시각화 지도(gis/gwangjin_scenario_a_map.html, gis/gwangjin_scenario_b_map.html) 생성.

## 📊 5. 시나리오 분석 결과 비교

### 5.1 시나리오 A vs B 종합 비교

* **[시나리오 A] 이론적 최적지 (`scenario_a`)**
  * **선정 장소:** 구의1동주민센터
  * **후보군 범위:** 광진구 내 공공 태양광 설치 시설 18개 전체
  * **총 물류운송부하:** **13.383 km·ton**
  * **이동 거리 효율:** 광진구 내 수학적/지리적 기준 최고 효율 1위
  * **물류 실현 가능성:** **⚠️ 실현 불가능** (주민센터 부지가 매우 협소하여 9t 이상 야적 및 11t 대형 트럭 하역 작업 불가)

* **[시나리오 B] 현실적 최적 거점 (`scenario_b`)**
  * **선정 장소:** 능동공영주차장 부지
  * **후보군 범위:** 대형 차량 진출입 및 9t 야적이 가능한 공공 유휴부지 4곳
  * **총 물류운송부하:** **13.989 km·ton**
  * **이동 거리 효율:** 이론적 최적지(구의1동) 대비 **운송부하 오차율 4.5% 미만**으로 물류 효율 손실이 미미함
  * **물류 실현 가능성:** **✅ 실현 가능** (평지 주차장 및 넓은 진입로 확보로 대형 윙바디 트럭 진출입 및 안전 야적 가능)

### 5.2 시나리오 B 공공 유휴부지 후보군 4개소 상세 분석
* **후보지 기본 설정:** 태양광 미설치 부지로 **자체 발생량은 0.000 ton**이며, 광진구 전체 물량인 **총 9.395 ton을 완충 집하·적재 가능한 거점 공간**임.

1. **🏆 1위: 능동공영주차장 부지 (최종 선정)**
   * **총 물류운송부하:** **13.989 km·ton**
   * **분석 결과:** 기준점 (0.0% 증가) / 관내 중앙부 위치 및 넓은 차고지 확보로 현실적 최적 거점으로 최종 선정.
2. **2위: 광진구 자원순환센터 차고지 (탈락)**
   * **총 물류운송부하:** 15.820 km·ton
   * **분석 결과:** 1위 대비 **+13.1% 운송부하 증가** / 광진구 북측 치우침으로 인해 이동 동선 비효율 발생.
3. **3위: 중곡동 공영 유휴부지 (탈락)**
   * **총 물류운송부하:** 16.450 km·ton
   * **분석 결과:** 1위 대비 **+17.6% 운송부하 증가** / 북동쪽 외곽 편중으로 탈락.
4. **4위: 자양4빗물펌프장 부지 (탈락)**
   * **총 물류운송부하:** 17.210 km·ton
   * **분석 결과:** 1위 대비 **+23.0% 운송부하 증가** / 남서쪽 외곽 치우침으로 물류부하 최대 발생.
